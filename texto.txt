 Muy bien, ya tenemos el stack definido:

- Lenguaje: Python (el estándar de la industria).
- Orquestador: Mage.ai
- Almacenamiento (Data Lake): AWS S3
- Transformación: SQL, Postgres
- Visualización: Un dashboard sencillo en Streamlit (Python) para mostrar que los datos son útiles. 


MASTERFLOW/
│
├── data_lake/                      # Simulación de almacenamiento en la nube (S3)
│   ├── raw/                        # Datos "sucios" en formato .parquet o .json
│   │   └── products_v1.parquet     # Archivo generado por el extractor
│   └── processed/                  # Datos pre-procesados (antes de entrar a Postgres)
│       └── cleaned_products.parquet
│
├── masterflow_project/             # Carpeta principal de Mage.ai
│   ├── pipelines/                  # Configuración de los flujos de trabajo
│   │   └── api_to_postgres/        # Carpeta del pipeline específico
│   │       └── metadata.yaml       # Archivo que le dice a Mage cómo conectar los bloques
│   ├── data_loaders/               # BLOQUE 1: Extracción
│   │   ├── __init__.py
│   │   └── get_mercadolibre_data.py # Script Python que consulta la API
│   ├── transformers/               # BLOQUE 2: Transformación
│   │   ├── __init__.py
│   │   └── clean_data.py           # Script Python para normalizar precios/nombres
│   │   └── calculate_metrics.sql   # (Opcional) Transformación usando SQL
│   ├── data_exporters/             # BLOQUE 3: Carga
│   │   ├── __init__.py
│   │   ├── save_to_local_lake.py   # Script que guarda el .parquet en /data_lake/raw/
│   │   └── export_to_postgres.py   # Script que inserta los datos en la base de datos
│   ├── io_config.yaml              # CONFIGURACIÓN CRÍTICA: Aquí defines la conexión a Postgres
│   └── metadata.yaml               # Configuración general del proyecto Mage
│
├── .env                            # ARCHIVO SECRETO: Tus contraseñas (DB_USER, DB_PASSWORD, etc.)
├── .gitignore                      # EL FILTRO: Evita subir archivos pesados o secretos a GitHub
├── requirements.txt                # LA RECETA: Lista de librerías para que el proyecto funcione
├── app_dashboard.py                # LA VITRINA: Código de Streamlit para ver los gráficos
├── README.md                       # EL CV DEL PROYECTO: Instrucciones y explicación para el reclutador
└── venv/                           # EL ENTORNO: Carpeta creada por Python (no se toca, solo se activa)
